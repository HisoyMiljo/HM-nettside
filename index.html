Om prosjektet

Et oppsett som er enkelt å videreutvikle med Codex.

Prosjektet er bevisst satt opp uten komplisert byggekjede for første fase. Det gjør at vi kan fokusere på innhold, uttrykk og publisering før vi eventuelt utvider med flere sider, skjemaer eller CMS.

A

Rask oppstart

Ingen tung konfigurasjon er nødvendig for å komme i gang. Filene kan versjoneres direkte i GitHub og publiseres rett fra repoet.

B

Netlify-vennlig

netlify.toml er lagt inn, så nettstedet kan deployes som en statisk side uten ekstra byggetrinn.

C

Bygget for vekst

Strukturen kan utvides med egne undersider for tjenester, referanser, kontakt, rekruttering eller miljøprofil når innholdet er klart.

Dette kommer

Naturlige neste utvidelser for den ferdige nettsiden.

Tjenestesider

Egne seksjoner eller undersider med konkret beskrivelse av hva Hisøy Miljø tilbyr, hvem dere hjelper og hvordan oppdrag gjennomføres.

Referanser og tillit

Kundesitater, bilder fra arbeid, sertifiseringer og annen dokumentasjon som bygger troverdighet.

Kontakt og konvertering

Telefon, e-post, geografisk område, kontaktskjema og tydelige knapper som gjør det enkelt å ta kontakt.

Fremdrift

Tre trinn fra oppstart til publisert nettside.

Trinn 1

Samle innhold

Fyll inn malen i docs/innhold-vi-trenger.md med tjenester, kontaktinfo, område, bilder, logo og ønsket tone.

Trinn 2

Bygg ferdig siden

Når innholdet er klart, bruker vi Codex til å skrive endelig tekst, sette inn ekte informasjon og bygge ut flere seksjoner eller sider.

Trinn 3

Publiser

Push prosjektet til GitHub og koble repoet til Netlify for automatisk deploy ved hver oppdatering.

Klar for neste steg

Send inn bedriftsinnholdet, så bygger vi resten av siden.

Det viktigste akkurat nå er å samle riktig tekst, bilder og kontaktinformasjon. Når det er på plass, kan Codex gjøre nettstedet klart for publisering på kort tid.
